Промпты

Простой сайт для хранения, поиска и публикации промптов для ИИ. Один HTML-файл, без сервера и сборки. Всё работает в браузере.

Возможности

- Публикация промптов: название и текст
- Поиск по названию и тексту
- Скачивание любого промпта в `.txt`
- Копирование текста в буфер обмена одним кликом
- Удаление промптов с подтверждением
- Загрузка промптов перетаскиванием файла (drag and drop): `.txt`, `.md`, `.json`
- Светлая, тёмная и авто-тема (подстраивается под систему)
- Плавное раскрытие формы публикации
- Кнопка «Наверх» при прокрутке
- Адаптивная вёрстка под телефон
- Данные хранятся локально в `localStorage`, ничего не уходит на сервер

Быстрый старт

1. Скачай файл `index.html`.
2. Открой его в браузере — двойным кликом или через `File → Open`.
3. Готово. Можно писать и публиковать промпты.
